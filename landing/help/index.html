Help

From page to PNG.

Capture, edit and export locally. Start with the action that matches your next step.

Choose a capture action

  • Capture & copy: capture the page and copy the original PNG. The editor stays closed.
  • Capture & save: capture the page and download the original PNG.
  • Capture & edit: open the local editor. No file or clipboard copy is created until you choose an export action.

Keep the popup open until capture finishes. Choose the page or its largest fully visible vertical scroll area. A completed preview lets you copy, save or edit the same capture without capturing again.

Install and open

Use an official store link on the home page when available. For local testing, download the matching archive from GitHub Releases. Chrome: extract the Chrome ZIP, open chrome://extensions, enable Developer mode and select Load unpacked. Firefox: extract the Firefox ZIP, open about:debugging#/runtime/this-firefox, select Load Temporary Add-on and choose manifest.json. Temporary Firefox installations end when the browser closes.

Open a normal webpage and select KoalaShot from your browser's extensions menu. Pin its button for easier access.

Copy did not work

Allow the optional clipboard permission when prompted. If the browser or operating system blocks copying, the result remains available: choose Copy again or Save to download it. KoalaShot never needs to read your clipboard.

A page cannot be captured

Browser settings, extension stores, built-in PDF viewers and other protected pages may block access. Use a normal webpage. Keep its tab active and avoid scrolling or resizing during capture. Wait for loading to finish before retrying a dynamic page. Extremely large pages may exceed safe canvas limits; horizontal stitching and partially visible internal scroll areas are unsupported.

Edit and export

Select an annotation to move it, duplicate it or change its style. Rectangular annotations have resize handles. Apply or cancel pending text and crop changes before exporting. Undo cancels an unfinished crop first. Use Fit after changing the window size, and open Keyboard shortcuts in the editor for the complete key list. Set a filename before saving.

Hide sensitive content

Use Redact for an opaque mask in the exported PNG. Blur and pixelation are cosmetic effects. The original stays unchanged in local temporary storage until you discard it or it expires. Files and clipboard copies already exported are outside automatic cleanup. See the privacy policy.

Draft conflict, damage or expiry

Two tabs editing the same capture can conflict. Load the latest draft, or keep your edits as a separate copy. Export pauses until the conflict is resolved. A damaged draft blocks export; recover an unedited original only if you intend to remove all annotations. Captures expire after 24 hours, including separate copies. An open editor deletes expired data; otherwise cleanup runs when KoalaShot next opens.

Still stuck?

Report a problem with the browser version, KoalaShot version, steps and exact error. Share a public example page when possible. Remove private page content from screenshots before attaching them.
