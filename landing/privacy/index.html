Privacy

Local by default.

KoalaShot is designed so the screenshot does not leave the browser profile.

What happens when you capture

KoalaShot captures only after you explicitly start Capture & Copy or Save PNG. The extension scrolls the active page, captures viewport sections, and stitches them into one PNG in local browser memory.

What we do not collect

  • Screenshots and page content are not uploaded.
  • There is no account, browsing-history collection, tracking, telemetry, analytics, or error-reporting service.
  • KoalaShot does not use cookies, remote configuration, advertising, or remote code.

Clipboard and downloads

Copying to the clipboard and saving a file are user-initiated actions. KoalaShot requests the optional clipboard permission only when Capture & Copy is selected, before capture begins. It does not read the clipboard and does not request the downloads permission.

Temporary editor captures

If you enable Open editor after capture, the original PNG is stored in extension-local IndexedDB so the packaged editor page can load it. Annotation drafts are saved alongside the same temporary record with debounced local writes. Temporary records expire after no more than 24 hours and can be discarded immediately in the editor. There is no screenshot history interface and records are not synchronized.

Access limitations

Browser-protected pages, extension stores, built-in PDF viewers, and other privileged pages may block extension access. KoalaShot does not work around those browser boundaries. No browsing history is collected as a result.
