Privacy

Local by default.

KoalaShot is designed so the screenshot does not leave the browser profile.

What happens when you capture

KoalaShot captures only after you explicitly start Capture & edit, Capture & copy, or Capture & save. The extension scrolls the active page, captures viewport sections, and stitches them into one PNG in local browser memory.

What we do not collect

  • Screenshots and page content are not uploaded.
  • There is no account, browsing-history collection, tracking, telemetry, analytics, or error-reporting service.
  • KoalaShot does not use cookies, remote configuration, advertising, or remote code.

Clipboard and downloads

Copying to the clipboard and saving a file are user-initiated actions. KoalaShot requests the optional clipboard permission when you select a copy action in the popup or editor. It does not read the clipboard and does not request the downloads permission.

Temporary editor captures

Choosing Capture & edit, or Edit on a completed capture, stores the original PNG in extension-local IndexedDB so the packaged editor can load it. Direct capture-and-copy and capture-and-save actions do not open the editor or store the original in IndexedDB; the result stays in popup memory until replaced or the popup closes. The capture also contains its source origin (scheme, hostname and port), page title, dimensions, filename and any completeness warning. New captures do not store the source URL path, query or fragment. Annotation and crop drafts, including revision counters, are stored locally; a tab-local sessionStorage journal protects unsaved edits during reload. Captures become unavailable after 24 hours and can be discarded immediately in the editor. An open editor deletes expired captures; if KoalaShot is closed, physical deletion occurs the next time its popup or editor starts. Redact covers pixels in exported PNGs; the temporary original remains unchanged until deleted. Downloaded files and copies already placed on the system clipboard are outside this automatic cleanup. There is no screenshot history interface and records are not synchronized. Concurrent editor tabs detect conflicting drafts and pause export. A separate copy retains the original expiry time. Damaged drafts block export; an unedited original can only be recovered through an explicit action.

Settings and support links

The selected capture area is saved in extension-local settings. A timestamp in browser session storage helps space screenshot requests; it contains no page content. Store and review metadata is packaged with the extension. Privacy, Legal, Help and review links open external websites only when clicked.

This website and contact

This policy describes extension processing. Visiting this website or a linked store sends a normal web request to that website and its hosting provider, separate from screenshot processing. No screenshots are sent by those links. For privacy questions, contact admin@koalastuff.net. Publisher information is available in the central KoalaStuff legal notice.

Access limitations

Browser-protected pages, extension stores, built-in PDF viewers, and other privileged pages may block extension access. KoalaShot does not work around those browser boundaries. No browsing history is collected as a result.
