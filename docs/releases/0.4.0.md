## Release and acceptance boundaries

GitHub publication is performed by the protected-branch PR and tag workflow. Read the actual [v0.4.0 release](https://github.com/Shik3i/KoalaShot/releases/tag/v0.4.0) and [Actions](https://github.com/Shik3i/KoalaShot/actions) for publication/check status; this document does not predeclare remote success.

Browser automation uses expanded test-only permissions and synthetic editor input. Manual toolbar activation with the shipped permissions, physical HiDPI/non-default zoom, target operating systems and Firefox minimum-version/ESR acceptance remain separate from automated coverage. Chrome Web Store/Firefox Add-ons submission and public website deployment are separate operations.
