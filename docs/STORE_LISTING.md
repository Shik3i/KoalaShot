This packet accompanies v0.6.2, with matching verified archives and regenerated product screenshots. Confirm the matching tag and verified artifacts on GitHub Releases. The website has not been deployed yet; its public privacy URL must work before store submission. Website deployment and store uploads are performed only by the owner.
