# Store listing packet

The maintained submission packet is in [store-assets](../store-assets/README.md), following KoalaSync's central StoreAssets organization.

- [English description](../store-assets/StoreDescription.md) and [prepared German translation](../store-assets/StoreDescription.de.md).
- [Chrome dashboard fields](../store-assets/ChromeWebStore.md): purpose, permission justifications, remote code and local-data disclosures.
- [Firefox notes](../store-assets/FirefoxAddons.md) and [reviewer instructions](../store-assets/ReviewerNotes.txt).
- [Release readiness](../store-assets/RELEASE_READINESS.md) and [official sources](../store-assets/SOURCES.md).

Five numbered 1280 × 800 images per browser, store icons, a small promo and marquee are supplied. Real product captures are composed with separate explanatory labels; raw captures and provenance are retained. These screenshots do not prove trusted toolbar activation.

This packet accompanies v0.5.3, including the camera icon and updated privacy/store text. Confirm the matching tag and verified artifacts on GitHub Releases. The website has not been deployed yet; its public privacy URL must work before store submission. Website deployment and store uploads are performed only by the owner.
